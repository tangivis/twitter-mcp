# ローカル XChat リーダー

XChat は X のエンドツーエンド暗号化 DM です。この機能は専用の永続
Chromium プロファイルで X の Web クライアントにローカル復号させ、表示済み
テキストをアクセシビリティツリーから読み取ります。

セットアップ、設計、セキュリティ、ログイン制限からの復旧手順は
[英語版のソース](https://github.com/tangivis/twitter-mcp/blob/main/docs/XCHAT.en.md)
を参照してください。Cookie、4 桁のパスコード、ブラウザプロファイルを Git に
コミットしないでください。
